# Mini Operating System Resource Monitor

A desktop-based simulation application built using C# WinForms that demonstrates how an operating system manages system resources such as CPU, memory, and I/O devices.

This project simulates core operating system concepts including process lifecycle, resource allocation, and system performance monitoring.

---

## Project Overview

The **Mini Operating System Resource Monitor** is an educational simulator designed to demonstrate how operating systems manage limited system resources.

Instead of accessing real hardware, the system creates a simulated environment where processes request CPU, memory, and I/O resources. The simulator applies operating system rules to allocate resources and manage process states.

This allows students to observe how operating systems handle resource management and process scheduling in a controlled environment.

---

## Key Features

- System resource configuration (CPU, Memory, I/O)
- Process creation and management
- Process state lifecycle simulation
- Resource allocation monitoring
- System performance metrics calculation
- Interactive desktop user interface
